# Glossary template

Keep the headings and the entry form exactly as written. Replace every
`<placeholder>`. Write one `##` section per subject, with its entries in
alphabetical order, one per term: `- **Term**: definition.`

---

```markdown
# Glossary

Every word below has two readings in <the document set: the files, or the
rule that selects them> that no other word settles. Each entry gives the one
reading that holds. <One sentence on where restatements live, when a document
restates entries. Example: A skill's Terms section restates the entries it
uses with the same text.>

## <Subject>

- **<Term>**: <what it is, as a noun phrase. Example: a user assigned the
  patient role in the app.>
```
